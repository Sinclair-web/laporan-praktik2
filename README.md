# Program Penghitung Nilai Mahasiswa

## Deskripsi
Program sederhana berbasis JavaScript yang dijalankan menggunakan Node.js. Program ini dibuat untuk memenuhi tugas praktik pengganti mata kuliah **Aplikasi Berbasis Service**.

## Fitur
- Menampilkan data mahasiswa.
- Menampilkan nilai tugas, UTS, dan UAS.
- Menghitung nilai akhir berdasarkan bobot.
- Menentukan predikat nilai secara otomatis.

## Ketentuan Nilai
- Tugas: 30%
- UTS: 30%
- UAS: 40%

Predikat:
- A: 85–100
- B: 75–84,99
- C: 65–74,99
- D: 50–64,99
- E: Di bawah 50

## Teknologi
- JavaScript
- Node.js
- Visual Studio Code

## Cara Menjalankan
Jalankan perintah berikut melalui terminal:

```bash
node penghitung-nilai.js
```
